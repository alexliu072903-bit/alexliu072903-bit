## 我在做什么

在 **AirJelly**，我负责 Agent Context 方向：把用户分散的 Context 整合起来，让 Codex、Claude Code 这类外部 Agent 掌握与当前任务相关的信息，同时让用户看得到、控制得了具体交出了什么。

我关心的是：当 AI 需要理解过去的决定、在正确时机采取行动，并把高影响的选择留给用户时，产品应该怎样工作。
